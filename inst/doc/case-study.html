Case study: cardiovascular health across the lifespan

This article works through a complete project with essential8: preparing survey data for children and adults, scoring Life’s Essential 8 (LE8), checking what was scored, and summarizing and plotting the results for a report. The data are simulated for 500 people aged 2 to 79 years.

library(essential8)
library(dplyr)

The study

Suppose a community health survey collected cardiovascular health measures for 500 household members aged 2 years or older. We are interested in:

  1. How many participants have enough data for an LE8 composite score?
  2. What is the distribution of cardiovascular health, overall and by life stage?
  3. Which LE8 components are weakest (have the lowest scores) at each life stage?

Prepare the data

Each participant needs the inputs for the components that apply at their age. The survey recorded:

  • the 16-item MEPA diet questionnaire for everyone (children aged 2-5 use 10 of the items, and their sweets include sugar-sweetened beverages);
  • daily active play for children aged 2-5, and weekly moderate and vigorous activity minutes from age 6;
  • nicotine exposure, secondhand smoke, and sleep;
  • BMI for adults, and the CDC BMI percentile and percent of the 95th percentile for children;
  • non-HDL cholesterol and glucose, where blood was drawn;
  • blood pressure, with the child’s AAP 2017 90th and 95th percentile thresholds at ages 1-12.

In a real project, the children’s growth-chart and blood-pressure reference values would come from height, weight, sex, and age with add_pediatric_references(), which uses the packages cdcanthro and pedbp:

survey <- add_pediatric_references(
  survey,
  sex = "sex",
  height = "height_cm",
  weight = "weight_kg"
)

preschool <- age < 6

sex <- sample(c("female", "male"), n, replace = TRUE)

diabetes <- !child & runif(n) < plogis(-4.2 + 0.05 * age)
smoking_status <- case_when(

  child ~ sample(c("never", "former", "current"), n, TRUE, c(0.8, 0.15, 0.05)),

# Heavier participants are more likely to have blood drawn, and their

The simulation leaves gaps where a real survey would have them: about a fifth of adults and nearly half of children had no blood drawn, so they have no lipid or glucose values. Blood was drawn more often for participants with a higher BMI, whose cholesterol and glucose also run higher. By default, missing values are not imputed: score_le8(impute = FALSE). If set to TRUE, the function uses multiple imputation with predictive mean matching to fill in missing values.

Choose a composite threshold

min_components sets how many of the eight component scores a participant needs for a composite score. The default of 7 suits adults with complete measurements, but AHA recommends averaging whatever components are available and appropriate for a child, and the NHANES analysis that accompanied the advisory averaged as few as three. Without blood results, a participant has six components.

Scoring with the default shows the cost for children:

default_threshold <- score_le8(survey)

default_threshold |>
  summarise(
    participants = n(),
    with_composite = sum(!is.na(le8_composite_score)),
    .by = le8_population
  )
#> # A tibble: 2 × 3

#> 1 pediatric               170             94
#> 2 adult                   330            266

Only 94 of the 170 children keep a composite score: those without blood results have six components, one short of the default. This study uses min_components = 6, so a participant needs every component except the two laboratory measures.

Find the weakest component

tidy() reshapes the scores into long format, one row per participant and measure, which suits questions about components rather than people. Here, each participant’s lowest-scoring component points to where improvement would help them most. Impute the missing laboratory values

Averaging the available components keeps everyone with six or more scores, but it treats each missing component as if it equalled the average of that person’s other scores. Dropping incomplete participants instead keeps only those who had blood drawn, who in this survey are heavier than average. Multiple imputation fills in the missing inputs several times, drawing on everything else known about each participant, and carries the uncertainty about them into every estimate.

le8_imputation_setup() shows what would be imputed. It imputes an input only for participants whose age uses it, and checks the observed values first:

le8_imputation_setup(survey)
#> LE8 imputation setup: 500 rows; 412 missing input values to impute in 3 inputs
#> 
#>                input applies_to missing impute method
#>  non_hdl_cholesterol        500     140    140    pmm
#>      glucose_measure        500     132    132 logreg
#>        glucose_value        500     140    140    pmm

score_le8(impute = ) runs the imputation with mice and then scores every imputed data set. Predictive mean matching draws each missing laboratory value from participants with similar BMI, age, and other measurements, and the setup keeps every imputed glucose value consistent with the participant’s diabetes status. le8_imputation_control() sets the number of imputations, the number of iterations, and a seed. This example uses 10 imputations to build quickly; a common rule of thumb for final analyses is at least as many imputations as the percentage of incomplete cases, here about 30.

After imputation, every participant has all eight components, so the default min_components = 7 applies to everyone:

imputed_scores <- survey |>
  score_le8(impute = le8_imputation_control(m = 10, maxit = 10, seed = 2026)) |>
  mutate(
    life_stage = cut(
      age,
      breaks = c(2, 6, 13, 20, 40, 60, 80),
      labels = c("2-5", "6-12", "13-19", "20-39", "40-59", "60-79"),
      right = FALSE
    )
  )

mice drops predictors that are redundant in an individual model and warns about each one; the mids object kept with the scores lists them in attr(imputed_scores, "mids")$loggedEvents. Here, diabetes is redundant with the HbA1c measure in the glucose models. The same object supports mice’s own diagnostics, such as plot(attr(imputed_scores, "mids")) to check convergence.

The summary pools each mean across the imputations with Rubin’s rules. The confidence intervals include the uncertainty from the missing values, and the fraction of missing information (fmi) shows how much of it comes from the imputations: about 0.13 for blood lipids and 0.17 for blood glucose, and close to zero for the components that were fully observed.

Because the data are simulated, the true laboratory values are known. The three approaches compare with them as follows:

true_scores <- score_le8(survey_complete)

compare <- function(scored, approach) {
  scored |>
    summarise(.by = le8_population) |>
    filter(measure %in% c("composite", "blood_lipids")) |>
    transmute(approach, le8_population, measure, n, mean = round(mean, 1))
}

bind_rows(

Complete cases understate the composite score in both populations because they over-represent participants with a higher BMI. Multiple imputation brings the blood lipid means closer to the true values, using the link between BMI and cholesterol, though it does not remove the bias entirely. Averaging the available components lands near the true composite here too, but it gives no estimate for the missing laboratory components and no way to carry their uncertainty into the results.

The other methods pool too. plot() draws pooled means, and the forest plot draws Rubin’s-rules confidence intervals:
